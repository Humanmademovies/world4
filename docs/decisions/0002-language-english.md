# ADR 0002 — English for code and documentation

- **Status:** accepted
- **Date:** 2026-06-14

## Context

The source spec and the maintainer communicate in French. The repository is
public and aims to align with international scientific projection scenarios.

## Decision

Everything in the repository — code, identifiers, commit messages, **and
documentation** — is written in English. A single documentation language keeps the
"docs always up to date" goal tractable.

## Consequences

- Lowers the barrier to external contributors and aligns with the (largely
  English) source literature and EXIOBASE/pymrio docs.
- French-language design notes, when needed, live outside the repo or in clearly
  marked appendices; they are not duplicated as a second maintained doc set.
